# Repentogon
## ¿Qué es Repentogon?
Repentogon es un mod para The Binding of Isaac: Repentance+ que extiende la Lua API con bug fixes, funcionalidades extra y mejoras de rendimiento.
## Instalación
La instalación recomendada se encuentra en el sitio web oficial https://repentogon.com/install.html.
