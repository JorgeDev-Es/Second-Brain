# Módulos de sead
En sead, un módulo es una división lógica y funcional del código que agrupa todas las clasese encargadas de un dominio específico del motor (`heap` parala memoria, `math` para matemáticas, `thread` para hilos, `container` para estructuras de datos).

### `basis`
Tipos fundamentales de ancho fijo, operadores `new`/`delete` personalizados y aserciones.
