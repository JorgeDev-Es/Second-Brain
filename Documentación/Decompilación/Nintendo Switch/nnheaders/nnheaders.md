# nnheaders
## ¿Qué es nnheaders?
nnheaders es un conjunto de archivos de cabecera creados mediante ingeniería inversa o fuentes disponibles de manera pública.

Escrito principalmente en C y C++.
## Propósito
Permite a proyectos de ingeniería inversa o frameworks de mods compilar código que se enlace correctamente con las funciones de los ejecutables de Switch
