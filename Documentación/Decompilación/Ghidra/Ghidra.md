# Ghidra
## ¿Qué es Ghidra?
Ghidra es un framework de ingeniería inversa de software (SRE) creado y mantenido por la Agencia de Seguridad Nacional. Incluye una suite de herramientas de análisis de software que permite a los usuarios analizar código compilado.
