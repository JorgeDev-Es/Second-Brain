# 1. Two Sum
## ¿Cuál es el problema?
Dado un array de enteros `nums` y un entero `target`, retorna los indices de los dos números que al sumarse obtengan el target.
Para cada entrada debería haber solamente una solución, y no puedes usar el mismo elemento 2 veces.
Puedes retornar la respuesta en cualquier orden.
## ¿En que te ayuda?
`map`
## Implementaciones
### Pseudocódigo

```
twoSum(numbers: List<integer>, target: integer): List<integer>
	if numbers.size <= 1 return []
	
	seenNumbers: Map<int, int>
	
	for i in range(numbers.size)
		actual: integer = numbers[i]
		difference: integer = target - actual
		
		if (seenNumbers.contain(difference))
			return [i, seenNumbers[difference]]
		
		seenNumbers.add(actual, i)
	
	return []
```
### C++
```C++
vector<int> twoSum(vector<int>& nums, int target) {  
    unordered_map<int, int> seenNumbers;  
	
	seenNumbers.insert({nums[0], 0});  
	
	for (int i = 1; i < nums.size(); i++) {  
		if (int complement = target - nums[i]; seenNumbers.contains(complement)) { 
	        return {seenNumbers[complement], i};  
	    } else {  
	        seenNumbers.insert({nums[i], i});
	    }  
	}  
	
	return {};
}
```

### C\#
```C#
int[] TwoSum(int[] nums, int target)
{
    Dictionary<int, int> seenNumbers = new Dictionary<int, int>();

    for (int i = 0; i < nums.Length; i++)
    {
        int actual = nums[i];
        int difference = target - actual;

        if (seenNumbers.ContainsKey(difference))
        {
            return [i, seenNumbers[difference]];
        }
        else
        {
            seenNumbers.TryAdd(actual, i);
        }
    }

    return [];
}
```
