# Dimensiones de Datos/Abstractas

Las dimensiones de datos describen cómo es algo.
- Son variables que no tienen por qué ser espaciales
- Cada dimensión representa una característica numérica e independiente.
- Se usan para representar puntos en un espacio n-dimensional, aunque no podamos visualizarlo.
- Usadas en:
	- Inteligencia artificial
	- Estadística
	- Ciencia de datos
	- Machine learning
	- Clustering, reducción dimensional, etc.

Ejemplo: una persona como vector → `[edad, altura, fuma?, colesterol, nivel de estrés]`  
→ eso vive en un espacio de **5 dimensiones abstractas**
