# Dimensiones Espaciales/Físicas
Las dimensiones espaciales describen dónde está algo.
- Son las que conoces del mundo real: ancho, alto, profundidad.
- Están relacionadas con la **geometría clásica**.
- Usamos ejes como $x$, $y$, $z$.
- Se pueden visualizar y medir con reglas, mapas o sistemas de coordenadas.
- Usadas en:
    - Gráficos 3D
    - Simulaciones físicas
    - Modelado 3D
    - Realidad virtual
    - Robótica

> Ejemplo: una caja tiene 3 dimensiones físicas: largo, ancho, alto.
