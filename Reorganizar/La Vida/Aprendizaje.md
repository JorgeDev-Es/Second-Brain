## Aprendizaje
## ¿Qué es el aprendizaje?
## ¿Qué es el verdadero aprendizaje?
El verdadero aprendizaje no es memorizar fechas, conceptos y fórmulas para no fallar en un examen.

## El objetivo principal del aprendizaje
El objetivo principal del aprendizaje no es conocer los conceptos que ves, sino aplicarlos para **resolver un problema**. Nadie te paga o te valora por saber matemáticas o programación, sino por usar esos conocimientos para resolver problemas reales.
## Aprender herramientas vs aprender modelos
Aprender a usar herramientas es generalmente un proceso lineal. Aprendes A, B, C y D, y estás listo para usar la herramienta, pero una herramienta no es lo importante.

Obtener conocimiento, generalmente, es un proceso lineal y finito. Aplicar el conocimiento para resolver un problema ambiguo es un proceso desordenado y no lineal.

"Puedes conocer todo el vocabulario, reglas gramaticales y la estructura de un idioma, pero eso no te hace un buen escritor."

No es necesario usar todo el vocabulario existente para escribir algo en específico. Algunas veces, necesitas escribir una idea simplificada en un párrafo y otras veces necesitas escribir un ensayo detallado. No se trata de saberlo todo para lograr escribir algo, sino de usar el vocabulario acertado para resolver el problema.

No es lo mismo saber cómo funciona un Array a decidir si un Array es la estructura de datos adecuada para tu problema.

"Debes entender el problema tan bien que la solución parezca obvia."
