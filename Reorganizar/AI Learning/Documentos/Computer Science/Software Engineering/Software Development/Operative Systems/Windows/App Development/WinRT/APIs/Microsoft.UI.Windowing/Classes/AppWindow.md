Es una API más moderna (parte de **Windows App SDK**) que ofrece **control avanzado sobre la ventana a nivel de sistema operativo**, por ejemplo:

- Cambiar tamaño y posición (`Resize`, `Move`).
    
- Cambiar título e íconos.
    
- Usar **overlays** o presentar ventanas como **toolwindows**.
    
- Trabajar con **múltiples monitores**.

- Soporte para escenarios de **multiventana real** (más allá de lo que da `Window`).
