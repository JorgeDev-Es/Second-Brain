# File System
The `node:fs` module enables interacting with the file system in a way modeled on standard POSIX functions.
```JavaScript
import "node:fs"
```
All file system operations have synchronous, callback and promise-based forms.

The `fs` module in Node.js is designed to behave similarly to the standard POSIX functions for file system operations. For example, the `fs.readFile()` function in Node.js is analogous to the `read()` function in POSIX.
