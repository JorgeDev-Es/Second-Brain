# Modules
Node.js modules can be considered APIs. Each module exposes a set of functions and objects that other parts of your Node.js application can use.
This fits the definition of an API: an interface for interacting with a software interface.

Los módulos de Node.js solo pueden ser usados cuando el contexto de ejecución sea Node.js, ya que no es posible usar los módulos de Node.js en el navegador.
