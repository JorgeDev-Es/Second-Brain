# Visual Studio Code
## Herramientas de desarrollo de primer nivel
Al ser VS Code el editor de código más popular, los desarrolladores crean herramientas de desarrollo, como compiladores, debuggers, etcétera; pensados para funcionar perfectamente con VS Code.
Sin embargo, existen algunos lenguajes que por su antiguedad o por su falta de herramientas integradas, el desarrollo se vuelve complicado y propenso a fallos, como C++.
