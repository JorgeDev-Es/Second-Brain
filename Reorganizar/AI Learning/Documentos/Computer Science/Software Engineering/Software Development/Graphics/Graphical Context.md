# Graphical Context
The graphical context 
## Vulkan instances
Vulkan also uses contexts, but slightly different. In Vulkan, a context is called instance. An instance is a representation of a Vulkan application in a system. Within an instance, they're created devices, command queues, and other object necessaries for rendering. Similar to OpenGL, a Vulkan device is associated with a specific Window.

>Meta
>"they're created devices" must be translated as "devices are created"
>**"Object necessaries":** Aunque se entiende el significado, "necessary objects" suena más natural.
