# Shaders
Shaders are small programs that tell a computer's graphics card how to render each pixel on the screen. They're written in specialized shading languages like GLSL or HLSL and are a crucial part of the modern graphics pipeline.

A shader is a program, written using the OpenGL ES Shading Language (GLSL), that takes information about the vertices that make up a shape and generates the data needed to render the pixels onto the screen.
## What shaders do
- Determine color and lighting.
- Create textures and patterns
- Implement post-processing effects
- Control geometry
## Type of shaders
### Vertex Shader
### Fragment Shader (Pixel shader)
### Tessellation shaders
### Compute shaders

Todos los tipos de shaders de GLSL, como los fragment shaders, vertex shaders, etc., se escriben en GLSL y no en C, C++ o WebGL.
