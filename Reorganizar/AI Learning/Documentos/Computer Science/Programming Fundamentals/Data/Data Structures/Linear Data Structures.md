# Linear Data Structures
## Key characteristics
- **Sequential arrangement**. Elements are organized in a straight line. Each element, except for the first and last, has a unique predecessor (the element before it) and a unique successor (the element after it).
- **Single-level data storage**. All data elements exist on the same "level" or plane. There's no hierarchical or branching arrangement (like you'd find in a tree or graph).
- **Sequential traversal**. You can typically traverse (visit) all the elements in the data structure in a single, continuous run, starting from one end and moving to the other.
- **Easy of implementation**
## Examples
Arrays
Linked lists
Stacks
Queues
