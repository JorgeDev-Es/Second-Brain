## Built-in types
Programming languages generally provide built-in functions and properties for working with their built-in data types. This is a core aspect of language design.
These build-in functionalities are essential for performing common operations on data.
## Types and Data Types
Data types are a subset of types.
Every data type is a type, but not every type is a data type.
Types encompass a broader range of concepts, including combinations and modifications of data types, as well as more abstract constructs like interfaces and function types.
