# Graphic Rendering Tools
Las interfaces de usuario, especialmente las gráficas (GUI), dependen de herramientas de renderizado para dibujar elementos en la pantalla. Sin embargo, la complejidad de este proceso está oculta tras capas de abstracción:
- Frameworks de UI. Proporcionan componentes predefinidos (botones, ventanas) y manejan automáticamente el dibujado, posicionamiento y animaciones.
## Las UI modernas parecen "magia"
La percepción de "magia" surge porque los sistemas operativos y aplicaciones ocultan la complejidad técnica detrás de una experiencia fluida y visualmente atractiva:
- Efectos visuales avanzados
- Aceleración por GPU
- Abstracción total
