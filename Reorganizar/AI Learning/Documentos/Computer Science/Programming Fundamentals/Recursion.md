# Recursion
Recursion is a fundamental programming technique where a function calls itself in order to solve a problem. This approach often involves breaking down a complex problem into smaller, more manageable sub-problems that are identical in nature to the original problem.
## How Recursion works
When a recursive function is called, it's added to the program's call stack. This stack is a data structure that keeps track of active functions. When the recursive function calls itself, a new instance of that function is added to the top of the stack.
## Examples of recursion
- Calculating factorial
- Fibonacci sequence
- Tree traversal
- Directory traversal
