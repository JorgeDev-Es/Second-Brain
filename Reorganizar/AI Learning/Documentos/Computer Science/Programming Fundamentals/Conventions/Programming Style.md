# Programming Style
El estilo de programación se refiere a las convenciones y métodos que se utilizan para escribir código, incluidas las decisiones sobre la legibilidad, simplicidad y el uso de características del lenguaje.
## Estilo idiomático y estilo orientado a la implementación
`Array.withIndex()` de Kotlin es un ejemplo del estilo idiomático
`Array.entries()` de JavaScript es un ejemplo del estilo orientado a la implementación.
