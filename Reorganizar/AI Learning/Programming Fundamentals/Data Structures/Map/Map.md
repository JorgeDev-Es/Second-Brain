# Map
Map
Es una estructura de datos propia de los lenguajes de programación, diseñada para ser manipulada directamente dentro del código ofreciendo un conjunto de operaciones específicas que facilitan su uso en algoritmos y estructuras de datos más complejas.

**Optimización de búsquedas**
Las implementaciones de Maps generalmente están altamente optimizadas para realizar búsquedas eficientes, lo que los hace ideales para almacenar y recuperar datos de forma rápida.

## Applications
### Reducción de la complejidad O(n^2)
Map can be used to reduce complexity in programming by replacing explicit loops and conditional statements with more declarative and concise code.
#### Búsqueda en tiempo constante
Un Map permite almacenar y acceder a elementos en tiempo constante O(1)
