# Programming Languages
## Development tools
Some languages prioritize a smaller, cleaner core language and leave the tooling to the community or third-party vendors.
Languages like C++ enters into this category.
The advantage is that the language itself remains more focused and potentially more portable. It also allows for competition and innovation in the tooling space.
Other languages adopt a more "batteries included" approach, providing a comprehensive set of tools as part of the standard distribution. This can simplify the initial setup and learning curve for developers. However, it can also lead to a larger, more complex ecosystem that can be harder to maintain and evolve.
