# Notas Musicales
## ¿Qué son las notas musicales?
Las notas musicales son una convención o estándar

Se combinan entre sí para formar melodías o para crear armonías.
## ¿Cuáles son las notas musicales?
Las notas musicales son Do, Re, Mi, Fa, Sol, La y Si en latín y C, D, E, F, G, A, B en el sistema inglés.

| Latín | Inglés |
| ----- | ------ |
| Do    | C      |
| Re    | D      |
| Mi    | E      |
| Fa    | F      |
| Sol   | G      |
| La    | A      |
| Si    | B      |
Do, Re, Mi, Fa, Sol, La y Si son llamadas notas naturales. Además existen notas musicales con alteraciones, conocidas como sostenidos o bemoles.
## Frecuencias
La cantidad de frecuencias utilizadas para notas musicales se ve limitada por nuestra capacidad auditiva. El oido solo responde a partir de 20 Hz y deja de responder alrededor de los 20,000 Hz
En el registro grave, la distancia entre notas es de apenas decimales.
En el registro agudo, la distancia entre notas es gigantesca.
Las notas musicales que los seres humanos podemos tocar o cantar se encuentran en el rango entre C1 y C7.
## El papel de las notas musicales en los instrumentos
Es muy importante memorizar las notas musicales en los instrumentos, pues permiten leer, interpretar, componer y comunicarse con otros músicos de manera adecuada.

Cada nota musical tiene asignada una frecuencia fundamental única y específica en hercios (Hz).
Cada subida de octava, la frecuencia se duplica.

| Nota | Frecuencia |
| ---- | ---------- |
| C1   | 32.70 Hz   |
| C2   | 65.41 Hz   |
| C3   | 130.81 Hz  |
| C4   | 261.63 Hz  |
| C5   | 523.25 Hz  |
| C6   | 1046.50 Hz |
| C7   | 2093.00 Hz |
