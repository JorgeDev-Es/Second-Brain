# Interfaz de Audio
## ¿Qué es una interfaz de audio?


Una interfaz de audio tiene un componente llamado Convertidor Analógico-Digital (ADC).
Si el voltaje recibido es 0V, el convertidor le asigna el número 0.
Si el voltaje es el máximo que la interfaz puede soportar, se le asigna el número más alto posible en código binario.
