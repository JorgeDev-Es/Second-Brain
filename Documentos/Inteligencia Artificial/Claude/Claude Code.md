# Claude Code
## ¿Qué es Claude code?
Claude Code es una herramienta de programación agentica que lee el código base, edita archivos, ejecuta comandos y se integra con tus herramientas de desarrollo. Es un asistente de código alimentado por inteligencia artificial que te ayuda a construir características, arreglar bugs, y automatizar tareas de desarrollo.
