# Fracciones
## ¿Qué es una fracción?
Una fracción es la representación de las partes de un todo. Representan un valor.
## Diferencias entre fracciones y divisiones
Una fracción es una representación mientras que una división es una operación.
Se suman fracciones, no se suman divisiones.

## ¿Qué significa que dos fracciones operen con diferente denominador?
Cuando dos fracciones operan con diferente denominador, significa que representan partes de una unidad dividida en un número distinto de partes.

Para poder realizar las operaciones de suma y resta, es necesario igualar los denominadores, es decir, expresar ambas fracciones con el mismo tamaño de partes.

La multiplicación de fracciones no requiere denominador común, por lo que se realiza de forma directa:
