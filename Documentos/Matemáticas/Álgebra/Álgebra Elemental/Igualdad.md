# Igualdad Algebraica
## ¿Qué es la igualdad algebraica?
Una igualdad es algebraica si posee incógnitas o variables.

Si la igualdad algebraica es verdadera para cualquier valor de las incógnitas o variables, es una identidad:
$$2x=x+x$$
En cambio, si solo es verdadera para ciertos valores de las incógnitas o variables, es una ecuación:
$$2x=8$$
