# Notaciones Matemáticas
## Matrices
### Notación para una matriz
Una matriz suele denotarse con letras mayúsculas, como $A$, $B$ o $C$.
### Notación para los elementos de una matriz

$$A_{ij}$$
donde $i$ representa la fila y $j$ la columna.
Los elementos se representa utilizando subíndices que indican las filas y las columnas
$$A_{m\times n}$$
