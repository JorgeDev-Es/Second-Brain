# Apego
## ¿Qué es el apego?
##
El concepto de apego no se inclina a lo positivo ni a lo negativo, sino que describe el vínculo en sí. Es el tipo de apego el que define cómo...

El apego es el prerrequisito para la independencia y la valentía, no una debilidad ni una necesidad de depender completamente de alguien de manera enfermiza.
