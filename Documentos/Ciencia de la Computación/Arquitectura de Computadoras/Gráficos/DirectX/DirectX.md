# DirectX
## Introducción
DirectX incluye soporte para gráficos 2D y 3D de alto rendimiento.
Microsoft DirectX proporcionan un conjunto de APIs que pueden usarse para crear juegos y otras aplicaciones multimedia de alto rendimiento.

Para gráficos 2D y texto, usar Direct2D y DirectWrite, Direct2D y DirectWrite fueron creados como un reemplazo moderno de GDI/GDI+ (Windows Graphics Device Interface).
