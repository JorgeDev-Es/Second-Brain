### Vectores en GLSL:

- **`float` (dimensión 1):** Un solo valor decimal.  
    Ejemplo: `float x = 0.5;`
    
- **`vec2` (dimensión 2):** Un vector con dos componentes (x, y).  
    Muy útil para representar posiciones 2D, coordenadas de textura, direcciones en plano, etc.
    
- **`vec3` (dimensión 3):** Un vector con tres componentes (x, y, z).  
    Se usa para colores RGB, posiciones 3D, normales de superficie, etc.
    
- **`vec4` (dimensión 4):** Un vector con cuatro componentes (x, y, z, w).  
    Usado para colores RGBA (donde A es alfa/transparencia), o para coordenadas homogéneas en gráficos 3D.
