# Expresiones Lambda
Las expresiones lambda, también conocidas 
## Terminología
Las expresiones lambda tiene como sinónimos los términos, dependiendo del lenguaje y convención:
- Funciones lambda
- Funciones de flecha (arrow functions)
- Funciones anónimas
- Funciones literales.
Provienen del cálculo lambda de Alonzo Church (1936), donde todas las funciones eran anónimas.
