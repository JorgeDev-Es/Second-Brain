## Ejemplos de variables
### C++
```C++
std::string my_variable = "This is a variable in C++";
```
### C\#
```C#
string my_variable = "This is a variable in C#"
```
### TypeScript
```TypeScript
let my_variable: string = "This is a variable in TypeScript"
```
### Python
```Python
my_variable = "This is a variable in Python"
```
## Nombrar variables de manera perfecta es casi imposible
Un nombre puede ser muy corto o muy largo, genérico o demasiado detallado, etcétera.
