# Programación
## ¿Qué es la programación?
La programación es el proceso de traducir una solución lógica a un conjunto de instrucciones que una computadora pueda entender y ejecutar.
La programación es el proceso de convertir ideas abstractas en realidades tangibles.

La programación no es un entorno aislado. No es posible crear un videojuego solo con la programación, es necesario convertir ideas, 
## La programación es un medio, no el fin
Conocer la sintaxis de un lenguaje de programación no hace que puedas crear un videojuego o un sistema de venta sin el conocimiento externo que te permita crearlo.
C++ no reproduce audio, sino que se conecta al sistema operativo mediante bibliotecas para reproducir audio. C++ no crea una imagen, sino que se conecta a una biblioteca gráfica para dibujar pixeles mediante instrucciones.
Hacerlo requiere creatividad, análisis de problemas, curiosidad.
