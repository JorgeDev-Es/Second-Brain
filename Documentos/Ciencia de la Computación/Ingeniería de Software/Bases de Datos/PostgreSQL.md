# PostgreSQL
## ¿Qué es PostgreSQL?
PostgreSQL es un sistema de base de datos Object-Relational. Usa y extiende el lenguaje SQL combinado con muchas características que almacenan de manera segura y escala la mayoría de cargas de trabajo complicadas.
