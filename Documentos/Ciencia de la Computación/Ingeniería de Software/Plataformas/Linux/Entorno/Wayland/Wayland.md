# Wayland
## Qué es Wayland?
Wayland es un protocolo de comunicación que define cómo un servidor gráfico se comunica con las aplicaciones gráficas y el hardware de entrada/salida en sistemas operativos Unix/Linux.

Sirve como el puente moderno entre el kernel de Linux y las aplicaciones. Define las reglas sobre cómo se dibujan los píxeles en memoría y cómo se entregan los eventos de entrada a cada ventana.

En Wayland, el servidor de pantalla, el gestor de ventanas y el compositor son un mismo proceso monolítico.
