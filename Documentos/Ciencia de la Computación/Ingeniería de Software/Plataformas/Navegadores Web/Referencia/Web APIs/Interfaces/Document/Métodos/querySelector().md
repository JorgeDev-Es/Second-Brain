# Método `querySelector()` de la Interfaz `Document`
## Descripción
`Document.querySelector()` devuelve el primer elemento del documento que coincida con el grupo especificado de selectores.

`querySelector` es una de las maneras de ]]seleccionar un elemento HTML
## Sintaxis
```JS
element = document.querySelector(selectors)
```
- `element` es un objeto de tipo [[Documentos/Ciencia de la Computación/Ingeniería de Software/Plataformas/Navegadores Web/Referencia/Web APIs/Interfaces/Element/Element]]
- `selectors` es una cadena de caracteres que contiene uno o más selectores CSS separados por coma.
## Detalles
`querySelector()` utiliza un recorrido primero en profundidad pre ordenado.
