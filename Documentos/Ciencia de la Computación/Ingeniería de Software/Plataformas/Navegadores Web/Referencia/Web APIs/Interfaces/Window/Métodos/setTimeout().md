# Método `setTimeout()` de la API `Window` de la Web API
## Descripción
El método global `setTimeout()` establece un temporizador que ejecuta una función específica una vez que expira el temporizador.
## Sintaxis
```TypeScript
function setTimeout(functionRef, delay, paramN...)
```
### Parámetros
##
### Retorno
El `timeoutID`
