# Método `clearRect()` de la Interfaz `CanvasRenderingContext2D`
## Descripción
El método `CanvasRenderingContext2D` convierte todos los pixeles en el rectangulo definido por el punto de inicio y tamaño a negro transparente, borrando cualquier contenido dibujado anteriormente.
