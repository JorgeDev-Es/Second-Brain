# Método `clearTimeout()` de la API `Window` de la Web API
## Descripción
El método global `clearTimeout()` borra el retraso asignado por [[Documentos/Ciencia de la Computación/Ingeniería de Software/Plataformas/Navegadores Web/Referencia/Web APIs/Interfaces/Window/Métodos/setTimeout()|setTimeout()]].
## Sintaxis
```TypeScript
function clearTimeout(timeoutID: number): void
```
### Parámetros
- timeoutID
### Retorno
void
