# DOM
## ¿Qué es el DOM?
El DOM, siglas en inglés de **Document Object Model** y en español **Modelo de Objetos del Documento**, conecta las páginas web a scripts al representar la estructura de un documento, como el HTML que representa una página Web, en la memoria.

El DOM representa un documento con un árbol lógico. Cada rama del árbol termina en un nodo y cada nodo contiene objetos.
