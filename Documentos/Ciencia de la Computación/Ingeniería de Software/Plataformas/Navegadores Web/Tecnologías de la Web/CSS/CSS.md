## ¿Cómo funciona CSS?
Cada navegador tiene su propio motor de renderizado, Chrome/Edge usa Blink, Firefox usa Gecko y Safari usa WebKit.

El motor de renderizado es el software que se encarga de todo el proceso de visualización de la página web, desde el HTML, pasando por el CSS, hasta el diseño y el pintado de la imagen final. Todo estos procesos usan APIs de bajo nivel para lograr renderizar la página web, por ejemplo, para los gráficos utilizan APIs como DirectX, Metal, Vulkan u OpenGL.

En lugar de que los desarrolladores manejen APIs de bajo nivel, las cuales suelen ser complejas y con un desarrollo lento, se desarrollo un lenguaje más simple: CSS.

CSS es una manera sencilla y declarativa para estilizar las páginas web. En lugar de enforcarte en el Cómo, te enfocas en el Qué. Son instrucciones sencillas y que trabajan en conjunto para lograr los diseños modernos de las páginas web.
