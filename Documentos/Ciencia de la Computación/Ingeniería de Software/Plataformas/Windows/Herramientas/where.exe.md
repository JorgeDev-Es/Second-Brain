# where.exe
## ¿Qué es where.exe?
where.exe es un ejecutable de Windows que muestra la ubicación de archivos que coinciden con el patrón de búsqueda.
De manera predeterminada, la busqueda se realiza en el directorio actual y en las rutas especificadas por la variable de entorno PATH.
`C:\Windows\System32\where.exe`
## Uso
```PowerShell
where.exe [/R dir] pattern...
```
## Parámetros
### `pattern`
## Opciones
### `/R`
