# Vortice
## Instalación
Instalar los paquetes Vortice.Windows via NuGet Package Manager o Package Manager Console.
```PowerShell
# Core foundation (usually required)
Install-Package Vortice.DirectX
Install-Package Vortice.DXGI

# 3D Graphics APIs
Install-Package Vortice.Direct3D11
Install-Package Vortice.Direct3D12

# 2D Graphics and Text
Install-Package Vortice.Direct2D1

# Shader Compilation
Install-Package Vortice.Dxc

# Audio
Install-Package Vortice.XAudio2

# Input
Install-Package Vortice.XInput

# UI Integration
Install-Package Vortice.WinUI Install-Package Vortice.WinForms
```
