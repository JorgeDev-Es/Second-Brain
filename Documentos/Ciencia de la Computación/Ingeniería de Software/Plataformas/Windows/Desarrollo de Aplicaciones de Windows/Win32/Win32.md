# API Win32
## ¿Que es Win32?
## Terminología
Win32 era el nombre de la API de Windows de 32 bits, y aunque el desarrollo moderno de Windows soporta 64 bits, el nombre Win32 se mantiene por compatibilidad.

También se suele usar el término WINAPI para referirse a la API de Windows.

## Control total
Al API Win32 es compleja, pero esa complejidad esta hecha para que los desarrolladores decidan el nivel de abstracción.
