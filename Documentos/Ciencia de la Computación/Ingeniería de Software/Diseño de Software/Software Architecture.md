# Software Architecture
La arquitectura de software es la estructura fundamental de un [[Documentos/Ciencia de la Computación/Ingeniería de Software/Diseño de Software/Software System|sistema de software]], conformada por sus componentes, las relaciones que existen entre ellos y los principios que guían su diseño y evolución.
## Beneficios
### En el sistema de software
### En el programador
- **Guía en el desarrollo**.
- **Reducción de la complejidad cognitiva**.
- **Mejor colaboración en equipo**.
- **Mayor productividad**.
- **Aprendizaje y profesionalización**.
- **Confianza en el código desarrollado**.

Una buena arquitectura de software facilita  la calidad, pero no la garantiza.
