# Diseño de Software
## ¿Qué es el diseño de software?
El diseño de software es el proceso de planificar y crear la estructura de un programa o aplicación.
Involucra desde la creación de la arquitectura hasta la definición de la interfaz de usuario.
## ¿Cuáles son los pasos del diseño de software?
Es fundamental modelar el dominio (la lógica núcleo) antes de diseñar el software.
## ¿Cuáles son los objetivos del diseño de software?
Crear software mantenible, flexible y escalable.
## Codificar no es diseño de software
Diseñar el software no solo se trata de escribir código, se debe tener una visión clara del producto final y de como los usuarios interacuarán con el.

El diseño del software determina el código fuente, no al reves.
