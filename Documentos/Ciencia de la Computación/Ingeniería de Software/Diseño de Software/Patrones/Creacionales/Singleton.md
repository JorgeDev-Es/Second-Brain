# Patrón Singleton
## ¿Qué es el patron Singleton?
El patrón Singleton es un patrón creacional que se encarga de crear una sola instancia de una clase y que este disponible en el resto de la aplicación.

## ¿Cuando usarlo?
Para servicios que manejan datos, conexión a base de datos o comunicación IPC.
