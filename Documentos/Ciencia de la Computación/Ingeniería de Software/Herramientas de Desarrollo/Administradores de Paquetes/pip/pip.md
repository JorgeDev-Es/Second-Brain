# pip
## ¿Qué es pip?
pip es un administrador de paquetes para Python.
## ¿De donde vienen los paquetes?
De manera predeterminada, pip busca los paquetes de Python Package Index, un repositorio de software para Python donde cualquiera puede subir paquetes.
