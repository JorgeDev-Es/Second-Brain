# Configuración de npm
npm obtiene sus configuraciones desde la línea de comandos, las variables de entorno y los archivos `npmrc`.
El comando [[Documentos/Ciencia de la Computación/Ingeniería de Software/Herramientas de Desarrollo/Administradores de Paquetes/npm/Referencia/CLI#`config`|npm config]] puede ser usado para actualizar y editar los contenidos del usuario y los archivos `npmrc` globales.
