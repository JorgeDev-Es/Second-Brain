# `npm`
## ¿Qué es `npm`?
`npm`, siglas de Node Package Manager
## Instalación de `npm`
### Actualizar npm
Para actualizar npm es necesario actualizar [[Documentos/Ciencia de la Computación/Ingeniería de Software/Entornos de Ejecución/Node.js/Node.js#Actualizar Node.js|Node.js]].
### Directorio de instalación predeterminado
El directorio de instalación predeterminado de npm es `C:/Program Files/nodejs` en Windows.
## Seguridad

```Powershell
npm config set min-release-age=7 --global

npm config set ignore-scripts=true --global
```
