# pnpm
## ¿Qué es pnpm?
pnpm es un gestor de paquetes para proyectos de Node.js que ofrece ventajas significativas en términos de almacenamiento y velocidad en comparación a herramientas como NPM o Yarn.
## Instalación de pnpm
sitio oficial de instalación https://pnpm.io/installation.

El directorio de instalación predeterminado de pnpm es: 
```
C:\Users\User\AppData\Loca\pnpm
```
