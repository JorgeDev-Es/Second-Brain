# Toolchains
Un toolchain es un conjunto de todas las **herramientas necesarias** para construir y ejecutar aplicaciones: El ejecutable de CMake (Para proyectos de CMake), herramientas de compilación, los compiladores de C/C++, el debugger, y el entorno de trabajo.
