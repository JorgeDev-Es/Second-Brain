# Plugin Vue.js para IntelliJ Platform
## Características
- Autocompletado de componentes, directivas, accesorios y métodos en plantillas.
- Navegación desde el componente, las directivas y los controladores de eventos hasta su definición.
- Asistencia de código de diferentes lenguajes dentro de las etiquetas `template`, `script` y `style` en archivos `.vue`.
- Extracción de componentes y refactorización de renombrado de componentes.
- Colección de code snippets para Vue.js.
- Nueva opción de proyecto Vue en la pantalla de bienvenida.
## TypeScript
Cuando se usa TypeScript dentro de una etiqueta `script`, WebStorm invoca `TypeScript Language Service` para type checking y mostrar errores detectados en las pestañas **Errores** y **Errores de compilcación** de la ventana de herramienta TypeScript.
