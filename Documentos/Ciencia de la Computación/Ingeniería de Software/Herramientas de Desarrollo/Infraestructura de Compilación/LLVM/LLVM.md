# LLVM
LLVM is a compiler infrastructure project, a collection of modular and reusable compiler and toolchain technologies.
It's designed to be flexible and powerful system for building compiler, interpreters, and other related tools.
Instead of targeting a specific architecture,  uses intermediate representation (IR), a low-level assembly-like language. This allows to developers to write a front-end for any source language and a back-end for any target architecture, all while leveraging the optimization and code generation capabilities of LLVM.
## LLVM IR
The intermediate representation is the heart of LLVM. It's a strongly typed, low-level language that provides a common platform for different programming languages and target architectures.
## LLVM IR and Java bytecode
Both serve as intermediate representations, allowing for platform independence and enabling optimizations.
