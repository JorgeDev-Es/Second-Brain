# Literals in Rust
## Integer literals
```Rust
let integer_literal: i32 = 32;

let integer_literal: i32 = -223;
```
### Unsigned integer literals
```Rust
let u_integer_literal: u32 = 43;

/* !!! */ let u_integer_literal: u32 = 43; // The literal `-23` does not fit into the type `u32`
```
