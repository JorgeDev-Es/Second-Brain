# Graphical User Interfaces In Rust
## GUI Apps Development
Rust doesn't have dedicated markup language or styling language with selectors like HTML, CSS, Vue, JSX, etc.
Instead, you define and configure UI elements, their properties, and their layout using standard Rust Code - calling functions, instantiating structs, using enums for messages/events, and chaining methods provided by the GUI library's API.

This can feel less intuitive initially compared to the declarative nature of HTML and CSS, especially if you are coming from a web development background. Building the UI elements and their hierarchy programmatically using Rust syntax is a different paradigm.

However, while the method is different, the goal is the same: to define a user interface that the application can render and interact with. Rust GUI libraries aim to provide the necessary components and abstractions within the standard Rust language structure to achieve similar leves of functionality and visual customization.
