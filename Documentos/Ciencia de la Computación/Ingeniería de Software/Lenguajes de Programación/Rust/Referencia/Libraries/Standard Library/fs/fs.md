# `std::fs` standard library
The `std::fs` module provides a set of tools for interacting with the filesystem. It offers functions and types to perform common operations like creating, reading, writing, deleting, and managing files and directories.

It provides an operating-system agnostic way to work with files and directories, although some functionalities might behave slightly differently depending on the underlying OS.
