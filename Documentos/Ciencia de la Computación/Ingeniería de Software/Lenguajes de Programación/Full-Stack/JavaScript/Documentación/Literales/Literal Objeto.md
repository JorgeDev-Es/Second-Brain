# Literal Objeto
Los objetos literales
## ¿Cuando usar literales objeto?
Los literales objeto son ideales para configuraciones constantes o utilidades que no tienen estado.

Si el objeto maneja un estado, entonces es mejor usar el [[Documentos/Ciencia de la Computación/Ingeniería de Software/Diseño de Software/Patrones/Creacionales/Singleton|patrón Singleton]].
