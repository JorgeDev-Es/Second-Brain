#### JavaScript, el núcleo del lenguaje (ECMAScript)
El núcleo del lenguaje es usado también en entornos fuera del navegador.

Entre algunas cosas, ECMAScript define:
- Sintaxis del lenguaje
- Mecanismos de manejo de errores
- Tipos de datos
- Un mecanismo de herencia basada en protocolos
- Funciones y objetos integrados
- Modo estricto
- Sistema de módulos
- Modelo de memoria básico
