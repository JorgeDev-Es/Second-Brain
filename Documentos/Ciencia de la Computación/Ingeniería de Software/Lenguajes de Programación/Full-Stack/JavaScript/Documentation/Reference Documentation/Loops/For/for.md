# for
El ciclo `for` permite iterar controlando explícitamente los índices.
## Características
### Control total
Puedes ajustar inicio, fin y paso del contador.
### Acceso a índices y valores
Directamente a través del índice.
### Flexibilidad
Útil para recorrer de adelante hacia atrás o saltar elementos.
## Cuando usarlo
Cuando necesites trabajar con índices o un control fino sobre la iteración.
