# Rendimiento de Electron.js
Electron no es más que una instancia de Chromium

El rendimiento de una aplicación de Electron jamás llegara al rendimiento de una aplicación nativa. Sin embargo, 

Visual Studio Code, un editor de código avanzado y utilizado por todo el mundo, logra un rendimiento y una experiencia casi indistinguible de una aplicación nativa.

La manera de lograr un buen rendimiento en Electron es entender como obtener un buen rendimiento en los navegadores web.
