# CLI de Python
## Uso
```PowerShell
python [script|file] [options]
```
## Comandos
### `-c`
```PowerShell
python -c <command>
```
### `-m`
Localiza el módulo usando el mecanismo de importación estándar y ejecuta su código como el módulo \_\_main\_\_.
```Powershell
python -m <module-name>
```
