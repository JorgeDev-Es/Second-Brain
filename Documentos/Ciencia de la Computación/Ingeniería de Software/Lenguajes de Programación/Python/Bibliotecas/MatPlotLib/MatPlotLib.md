# Biblioteca `MatPlotLib` de Python
## ¿Qué es `MatPlotLib`?
`MatPlotLib` es una biblioteca de gráficos de bajo nivel

```PowerShell
pip install matplotlib
```

```Python
import matplotlib
```
La mayoría de las utilidades de `MatPlotLib` se encuentran dentro del submódulo `pyplot`, y es generalmente importado con el alias `plt`.
```Python
import matplotlib.pyplot as plt
```
