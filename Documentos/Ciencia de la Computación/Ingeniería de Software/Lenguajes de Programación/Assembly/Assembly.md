# Assembly
## ¿Qué es assembly?
Assembly es un lenguaje de programación de bajo nivel diseñado para una arquitectura de computadora particular.

Assembly es convertido en código máquina ejecutable.

A diferencia de lenguajes de programación de alto nivel, Assembly 
- Como los datos son representados en memoria y otros dispositivos externos.
- Como el procesador accede y ejecuta instrucciones
- Cómo las instrucciones acceden y los datos y los procesan.

Para ejecutar un programa, el sistema copia lo copia de un dispositivo externo hacia la memoria interna, luego el procesador ejecuta las instrucciones del programa.
