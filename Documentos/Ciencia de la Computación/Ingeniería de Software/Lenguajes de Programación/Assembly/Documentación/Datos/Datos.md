# Datos
## Tamaño de los datos

| Word       |                                |
| ---------- | ------------------------------ |
| Doubleword | Un objeto de 2 bytes (16 bits) |
| Quadword   | Un objeto de 4 bytes (32 bits) |
| Paragraph  | Un objeto de 8 bytes (64 bits) |
| Kilobyte   | Un área de 16 bytes (128 bits) |
| Megabyte   | 1,024 bytes                    |
| Gigabyte   | 1,048,576 bytes                |

Existen dos tipos de direcciones de memoria:
- Memoria absoluta. Una dirección de referencia específica de una ubicación específica.
- Memoria segmentada (o offset). Dirección de memoria inicial segmentada con un valor de offset.
