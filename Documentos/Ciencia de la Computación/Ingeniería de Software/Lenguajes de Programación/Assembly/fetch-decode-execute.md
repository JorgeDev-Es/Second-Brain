# Ciclo fetch-decode-execute
## ¿Qué es el ciclo fetch-decode-execute?
El ciclo fetch-decode-execute es el proceso por el cual el procesador controla la ejecución de las instruciones

1. Fetching las instrucciones de la memoria
2. Decodificar o identificar la instrucción
3. Ejecutar la instrucción

El procesador puede acceder a uno o más bytes de memoria a la vez.

El procesador almacena datos en una secuencia de bytes inversa, un byte de bajo orden es almacenado en una dirección de memoria baja y un byte de alto orden en una dirección de memoria más alta.
