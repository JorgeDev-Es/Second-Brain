# Hello World!
```Kotlin
fun main() {
	println("Hello World!") // $> Hello World
}
```
- `fun` is used to declare a [[Documentos/Computer Science/Software Engineering/Software Development/Programming Languages/Kotlin/Documentation/Reference Documentation/Functions/Functions|functions]]
- The `main()` function is the [[Documentos/Computer Science/Software Engineering/Software Development/Programming Languages/Kotlin/Documentation/Reference Documentation/Entry Point|entry point]].
- The body of a function is written within curly braces `{}`.
- `println()` and `print()` functions print their arguments to standard output.
