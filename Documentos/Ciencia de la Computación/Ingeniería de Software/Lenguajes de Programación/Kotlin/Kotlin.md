# Kotlin
## ¿Qué es Kotlin?
Kotlin es un lenguaje de programación desarrollado por JetBrains.

## Ecosistema
### Entornos de ejecución
#### JVM
La Java Virtual Machine es el principal entorno de ejecución de Kotlin.

### Librerías estándar
Las librerías estándar de Kotlin proporcionan herramientas que no están en Java, como extensiones para colecciones, manipulación de archivos, programación funcional, etc.
