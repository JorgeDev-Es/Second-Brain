# C++
## ¿Qué es?
C++ es un lenguaje de programación de alto nivel de propósito general.

C++ es una extensión del lenguaje de programación C.
C++ también es conocido como "C con abstracciones" (incluso más exacto sería decir "C con abstracciones de alto nivel"). C++ nació como una extensión de C, sin embargo, el C++ moderno va más allá de ello.

## Características
### De propósito general
Con C++ es posible desarrollar sistemas operativos, compiladores, videojuegos, software de simulación científica, aplicaciones financieras, control de hardware, sistemas embebidos, etcétera.
### Multiparadigma
C++ soporta multiples paradigmas: Paradigma imperativo y estructurado, programación orientada a objetos, programación genérica y programación funcional.

C++ fue diseñado con el principio de zero-cost abstractions.
## Ventajas y desventajas
### Ventajas y desventajas frente a otros lenguajes
#### C
C y C++ no compiten entre si, sino que C es un lenguaje de sistemas mientras que C++ es un C con abstracciones.

C es un lenguaje de programación que se traduce muy cercano al ensamblador, mientras que C++ tiene abstracciones que pueden generar código oculto.

C++ puede actuar a tan bajo nivel como C puro, sin embargo, es menos simple y predecible, depende de un runtime y no obliga al programador a ser explícito, características claves de C.
