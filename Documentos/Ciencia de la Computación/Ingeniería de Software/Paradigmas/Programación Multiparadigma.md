# Programación Multiparadigma
## ¿Qué es la programación multiparadigma?
La programación multiparadigma es la capacidad de un lenguaje para combinar multiples paradigmas de programación en la solución de un problema.

|**Tarea**|**Paradigma**|**¿Por qué?**|
|---|---|---|
|**Configuración inicial**|**Imperativo**|Porque necesitas un control exacto paso a paso (Abrir DB -> Leer JSON -> Iniciar App).|
|**Interfaz (UI)**|**Declarativo**|Porque es más fácil decir "quiero que el botón sea azul" que programar los píxeles (HTML/React).|
|**Modelado de Datos**|**OOP**|Porque encapsular una "Canción" en un objeto con sus métodos es intuitivo y ordenado.|
|**Lectura de Disco**|**Asíncrono**|Para que la UI no se congele mientras el disco duro (I/O) busca los archivos.|
|**Cálculo de Metadatos**|**Paralelo**|Para usar todos los núcleos de la CPU y terminar en 1 segundo lo que tardaría 8.|
|**Sincronización Total**|**Reactivo**|Para que todo lo anterior se comunique sin que tú tengas que escribir miles de `if` manuales.|
