# Interfaz de Línea de Comandos de fnm
## Uso
## Comandos
### `list-remote`

| Aliases | `ls-remote` |
| ------- | ----------- |

`fnm list-remote` muestra todas las versiones de Node.js remotas.
### `list`

| Aliases | `ls` |
| ------- | ---- |

`fnm list` muestra todas las versiones de Node.js instaladas localmente.
### `install`

| Aliases | `i` |
| ------- | --- |
`fnm install` instala una nueva versión de Node.js.
