## Instalación
Las instrucciones de instalación oficial de Node.js se encuentran en el sitio web https://nodejs.org/en/download.

El directorio de instalación predeterminado de Node.js es:
```
C:\Program Files\nodejs
```

Agregar al Path del sistema:
```
C:\Program Files\nodejs
```
