# HTTPS
## ¿Qué es HTTPS?
HTTPS, siglas de Hypertext Transfer Protocol Secure, es un protocolo de la capa de aplicación en el modelo del protocolo de internet.
## Diferencia entre HTTP y HTTPS
Mientras que HTTP transmite los datos en texto plano sin encriptación, HTTPS encripta los datos usando TLS/SSL, haciendo que la comunicación sea más segura.
