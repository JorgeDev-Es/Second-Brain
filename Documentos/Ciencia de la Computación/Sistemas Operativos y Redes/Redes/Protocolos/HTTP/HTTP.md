# HTTP
## ¿Qué es HTTP?
HTTP, siglas de Hypertext Transfer Protocol, es un protocolo de la capa de aplicación en el modelo del protocolo de internet.
HTTP permite que las solicitudes (**requests**) y respuestas (**responses**) entre clientes y servidores tengan un determinadoformat a respetar para que puedan comunicarse sin inconvenientes
## Métodos de solicitudes (**Request Methods**)
Los métodos de solicitudes (**Request Methods**) son acciones específicas que seran
GET, POST, PUT, DELETE, HEAD y OPTIONS
